How this figure is made

Each panel opens one step on the way from the report file to the picture, with the equation it uses.

The measure: compression ratio the height of each column
ρi = c(reporti) / c(instructioni)

For delegation i, c(·) counts characters. ρ below 1 would mean the subagent sent back less than it was given, and ρ above 1 means more. Across the 26 delegations ρ runs from 1.2456 to 23.65, the mean is 5.6511, and the median is 4.3843, which is the average of the 13th and 14th values in sorted order (4.3694 and 4.3992).

From ratio to column height the log scale
h(ρ) = 3.4 · ln ρ / ln 30

The floor sits at ρ = 1, where ln 1 = 0, so a report the same length as its instruction would have no column at all. A ratio of 30 would reach 3.4 units. On a log scale every doubling adds the same height (3.4 · ln 2 / ln 30 ≈ 0.69), which is why the tick marks for ×2, ×5, ×10 and ×20 are not evenly spaced. The shortest column is h(1.2456) ≈ 0.22, the tallest h(23.65) ≈ 3.16, and the red median bar sits at h(4.3843) ≈ 1.48.

Columns stand left to right in the order the report lists them, 0.38 units apart. That order has no meaning. Only the height is data.

Related measures on the 2D page content gain and the matched null
gi = |V(reporti) \ V(instructioni)| / |V(reporti)|

Content gain as the 2D page describes it: the share of the report's content-word types (after a stoplist frozen before the run) that never appear in the instruction. The median is 0.8387, so most of a typical report's vocabulary was new.

Δ = r̄observed − r̄null = 0.9356 − 0.8732 = 0.0624

Retention is the share of a child's new vocabulary that later shows up in the parent's own prose. On its own, 0.9356 looks like nearly everything survives. The matched null replaces each child's new vocabulary with new vocabulary drawn from the other delegations, 200 draws per delegation, and still gets 0.8732, because the parent writes so much that almost any word turns up somewhere. The real effect is the difference, 0.0624. It is small but consistent: 25 of 26 delegations sit above their own null.

What the motion does Play and the slider

Play highlights one column every 0.8 seconds in report order and prints its exact ratio. The slider does the same by hand and works with reduced motion switched on. The scene draws nothing while it is still.

Where the numbers and code live

The 26 ratios are the delegations[].compression_ratio array from ma13_real_subagent_report.json, copied from the D1 chart on the 2D page, which lists every report key. The drawing code is the script at the bottom of this page, using assets/fig3d.js and Three.js r128.

In plain words

What you are looking at

  • Each column is one time an AI coding agent handed a task to a helper agent (a subagent) and got a written report back. These are 26 real hand-offs, recorded during earlier work and measured afterwards.
  • The height of a column is how many times longer the report was than the instruction that asked for it.
  • The floor means "the same length". The red line marks the typical hand-off, where the report came back about 4.4 times longer.
  • The scale is logarithmic, so the tallest column (23.65 times) doesn't squash all the others flat.

What it shows

Not one report came back shorter than its instruction. Even the shortest ran about a quarter longer. The prediction made before the run was the opposite.

Why it matters

Engineers often describe handing work to a subagent as a filter that narrows things down. In volume, at least, it did the reverse every time. That matters for the dissertation's use of Lotman. In Lotman's scheme, ordinary sending keeps a message the same size, so this is not that. Talking to yourself can make a message grow, but only through form, with no new facts, and most of these reports' words were new, so it is not that either. The rooms figure shows where that leaves AI delegation: in a corner his typology never named.

One caution travels with every number here. The transcripts don't record what the subagents read, so this figure can't tell new material that was looked up from new material that was made up. MA10 takes that question on directly.
