Part I · Brief summary

One sentence

Semiosis is not a point in one embedding space; it is typed relay across incompatible document surfaces, and machine systems that merge registers reproduce embassy-shaped readings.

What we are not claiming

  • Words → one universal vector plane → “meaning.”
  • Cosine neighborhood = understanding.
  • The probe replaces pair-read.
  • Montreal 1983 legislates a law of culture.
  • Explosion is proven (L3 is gated).
  • Generative models should write “the public version” of a memo.

What we are claiming

  1. Register is part of the sign-event. The same famine language does different work on spr. 1206 and on an embassy release five weeks later.
  2. Operators are measurable. Scare quotes, gathering vs symposium, drought-and-kulak denial form an operator × surface tensor (L2). Gaps in the tensor are as real as peaks (48 internal scare-quote hits, 0 outward in the pilot matrix).
  3. Relay is partial. Some thematic fields cross (famine, Canada, anniversary); some operators do not (symposium has no outward Montreal sentence).
  4. Silence is a coordinate. Domestic Pravda/Izvestiia not printing the drought frame in the processed 1983 window is evidence about which channel carries which job, not “missing data.”
  5. Frozen embeddings already encode the failure mode. A secret→outward linear map fits in-sample pairs but does not align secret text with Weekly/CIUS rivals; сборище lands near drought; scare-quoted symposium near Khmil’s “lie” sentence.

1 · Core thesis

Semiosis is not a point in one vector space. It is typed relay across document surfaces that obey different grammars on the same calendar week.

When institutional language crosses from secret report to embassy release to diaspora press, operators change (quotation marks, meeting names, famine frames) even when themes persist (Canada, anniversary, famine). Generic embeddings mostly recover theme-level gravity; they fail register-faithful relay unless structure is imposed.

One-sentence version: The gap in an operator × surface tensor is where ideology lives; machine cognition that averages registers fills that gap with embassy-shaped summaries.

2 · Why the usual “vectored plain” fails

2.1 Default ML picture

  • One manifold (e.g. cosine space of embeddings).
  • Neighborhood ≈ similarity ≈ meaning.
  • More data smooths noise; multilingual alignment shares a language-neutral core.

2.2 What the archive falsifies

Montreal 1983 shows non-mergeable coordinates on the same event:

Internal (spr. 1206, 24 Mar 1983)Outward (embassy, 28 Apr 1983)
Hostile “gathering”Drought, kulak sabotage
“Symposium” in scare quotesNo Montreal name
“Artificial famine” quoted as lieDenial of artificial famine

These are not dialect variants. They are incompatible reader contracts on the same commemorative season.

2.3 Lotman’s correction (operationalized)

From Lotman and Uspenskij (dual models; no neutral sphere) and Lotman (bilingual filters at the boundary):

  • The boundary is a sum of filters, not a line between “Soviet” and “Western.”
  • What cannot pass is structurally real (untranslatable), not failed translation.
  • Silence (domestic newspapers not carrying the drought frame in the processed 1983 audit) is a channel assignment, not absence of evidence.

L1-L3 attempt to draw this so it can be checked against pair-reads, not sit as metaphor in chapter one.

3 · What gets mapped (object type)

3.1 Not a token

A sign-event is minimally:

  • a stretch of text (sentence to memo section);
  • on a surface (secret memo, autocommunication report, embassy/Novosti, UN, domestic paper, diaspora press, scholarly rival);
  • on a date (or narrow window);
  • with active operators (scare quote, gathering recode, drought frame, slander frame, etc.);
  • at a proof tier (primary, tier-B processed, documented miss, not claimed).

Vectors attach to sign-events, not to lemmas. “Famine” is not one point; “famine”-as-scare-quoted-lie on spr. 1206 and “famine”-as-drought on embassy are different events.

3.2 Register → shell map (L1)

ShellSurfaces
1Secret KGB informational memos
2Autocommunication (I-I reports: office to itself)
3Soviet outward tier (embassy, Novosti alias, UN)
4Rival / diaspora / mainstream foil, scholarly counter-text

Novosti = embassy English in this corpus (verbatim outward packet). Treating Novosti as independent evidence double-counts the same release.

Pravda / Izvestiia / Rad ykr: separate clock; absence of drought frame in processed 1983 search is a finding (outward-only denial routing), not a gap to ignore.

4 · Three geometries (L1 / L2 / L3)

4.1 L1 · Semiosphere = topology of relay

Question: Where does each text sit, and which arcs are licensed?

  • Nodes: surfaces (13 in empirical pilot).
  • Edges: relay arcs with proof tier (proven thematic relay; tier-B processed; promising pending clip; not claimed).
  • Forbidden / missing arcs are first-class (no Pravda arc for drought frame; embassy packet does not name Montreal).

Semiotic stake: Location in culture = relay position, not frequency.

ML stake: Knowledge graphs need edge types and blocked edges, not only similarity cliques.

4.2 L2 · Operator tensor = the honest “plain”

Question: Which operators fire on which surfaces?

O[operator, surface] = count
What this equation says in plain language

This is not a neural-network tensor. It is a counting grid built from pair-read coding of the archive: “how many times does this wording habit appear on this kind of document?”

  • Each row is an operator - e.g. scare_quote_artificial_famine, symposium_recode, drought_kulak_denial.
  • Each column is a surface - spr. 1206, spr. 1208, embassy release (28 Apr 1983), Novosti alias, Khmil at the UN, Ukrainian Weekly, etc.
  • Each cell is a tally from the pilot matrix in register_relay_experiment.json.

When O[scare_quote, embassy] = 0, that is a finding: the embassy release does not carry internal scare-quote grammar. The gap is where the filter lives - not sampling noise. When O[drought_kulak_denial, embassy] > 0, the outward shell is doing a different job with famine language than spr. 1206 (quoted lie → natural-cause denial).

Example operators:

  • scare_quote_artificial_famine
  • symposium_recode (→ gathering / сборище)
  • drought_kulak_denial
  • nationalist_slander_frame (Khmil UN)

Pilot skew (internal vs outward): 48 scare-quote hits on internal memos, 0 on embassy/Novosti/UN in the same window - hard non-equivalence, not sampling noise.

Y ≈ W X    (W orthogonal - rotation only)
What this equation says in plain language

The probe asks a narrow question: if you treat secret memo sentences and outward public sentences as two clouds of numeric fingerprints, can you rotate the secret cloud so paired stretches line up with their embassy/UN counterparts?

  • X = matrix of secret-side embeddings (spr. 1206 famine line, spr. 1208 leak line, …).
  • Y = matrix of outward-side embeddings (embassy drought sentence, Khmil slander sentence, …).
  • W = the rotation map fit on nine licensed secret→outward pairs from pair-read.

In-sample cosine 0.613 means paired points align better after rotation than with no map (identity 0.025) or shuffled pairings (0.057). That confirms theme-level relay is linearly available in a generic encoder - famine talk in March and April still “points” in related directions.

It does not mean the model understands KGB intent. When the same W is applied to rival targets (Weekly, CIUS), alignment collapses (orth −0.025 vs identity 0.203): the map is pairing-specific, not a general Soviet→diaspora translator. Сборище landing near drought is theme gravity, not proof that gathering “means” drought historically.

cos(θ) = (x · y) / (‖x‖ ‖y‖)
What this equation says in plain language

After centering and normalizing embeddings (Artetxe preprocessing), cosine measures the angle between two fingerprint arrows - how much they share topic direction.

  • High cosine ≈ same neighborhood (famine near famine, Canada near Canada).
  • Near zero or negative ≈ not pointing the same way - used to show secret→outward map does not send internal stretches toward Weekly/CIUS rivals.

Cosine is the probe’s ruler for “did the map land on the right outward sentence among candidates?” It is not a warrant for historical paraphrase. Pair-read remains the warrant; cosine is a check on false averaging.

5.3 Epistemic role of the probe

The probe is a microscope, not an oracle:

  • Confirms: Thematic relay is linearly available in a generic encoder; register merge is not justified by in-sample fit alone.
  • Does not confirm: LLM “understanding,” generative reconstruction of memos, or global Lotman law.
  • Use in prose: Falsify false survey and single-manifold summaries; do not lead SSHRC or dissertation lede.

6 · Proposed coordinate system (extrapolation)

Generic embeddings supply unchosen axes. Lotman’s question requires named fibers:

Fiber / axisEncodes
Shell sWhich filter applies (1-4)
Date tCalendar layer (1983 anniversary vs 1955 habit baseline)
Operator vector oActive recoding habits on this stretch
Proof tier pWhat warrant licenses an edge
Relay direction dinternal → outward → rival → domestic silence
Grainstretch / document / office (E4 grain experiment)
sign-event = (s, t, o, p, d) + stretch text
What this equation says in plain language

A sign-event is not one dot in embedding space. It is an address in a coordinate system you choose from the archive - plus the actual sentence.

  • s = 1, t = 1983-03-24: spr. 1206 secret memo in the Montreal anniversary window.
  • o includes symposium_recode, scare_quote_artificial_famine - the operators pair-read marks active.
  • p = primary because the fond memo is in hand; p = documented miss when the embassy release omits Montreal.
  • d = internal → outward names which relay direction you are scoring (toward embassy/Novosti, not toward Weekly).

Two stretches can share a lemma (“famine”) but sit at different coordinates - which is why the probe attaches vectors to sign-events, not to dictionary entries.

6.1 Partial maps and untranslatables

Translation between shells is a partial function (not every input has an output):

Ts→s′ : os ↦ os′ ∪ {⊥}
What this equation says in plain language

Read left to right: “Rule for moving from shell s to shell s′ takes the internal operator bundle os and either produces an outward operator bundle os′ - or returns ⊥ (no translation exists).”

  • Transformed relay: internal quoted “artificial famine” as enemy lie → outward drought-and-kulak denial (same famine field, different operators).
  • Forbidden / ⊥: scare_quote_artificial_famine → ⊥ on shell 3 - zero column in O[operator, surface]; the embassy never speaks in internal scare-quote grammar.
  • Documented miss / ⊥: rival-sense “symposium” at UQAM → ⊥ on embassy shell - spr. 1206 tracks the meeting; the 28 Apr 1983 release never names Montreal.

Treating relay as a total function would invent outward sentences the archive refuses. Partial maps keep refusals and silences as first-class geometry.

Examples from Montreal:

  • scare_quote_artificial_famine → ⊥ on outward shell (zero column in L2).
  • symposium (rival sense) → ⊥ on embassy shell (documented miss on meeting name).
  • Thematic famine field → drought frame (transformed relay, not copy).

Documented miss (embassy release does not name Montreal) is obstruction: the morphism does not exist for that operator on that date.

6.2 Sheaf intuition (informal)

  • Local patches: each shell has its own speakable operators.
  • Gluing maps: only where pair-read proves relay; tier labels say how strong the glue is.
  • Obstruction: ⊥ and silence columns prevent global merge.

7 · Implications for semiotics

  • Structure and history: 1955 manual = grammar habit; 1983 = rewrite under public defeat.
  • Reference and social action: Operators are action types with measurable surface skew (Ahearn / Fairclough).
  • Untranslatability: Lotman’s filter = zero tensor column, falsifiable on new memos.
  • Dual models: Weekly vs embassy - averaging them is a reading mistake made literal in embedding space.
  • Silence: Trouillot meets geometry - domestic silence constrains what Novosti/embassy are doing.
  • Graphical Lotman: L1-L3 + proof tiers = first operationalization tied to archival epistemology.

Glossary · lay terms for this project

Tensor (L2 operator tensor)
Think of a spreadsheet: rows are wording habits (scare quotes, “gathering” instead of symposium, drought denial), columns are where texts live (secret memo, embassy release, UN speech). Each cell counts how often that habit appears on that surface. An empty cell is not “we forgot to look” - it means that habit does not speak on that surface. Example: 48 scare-quote hits on internal memos, 0 on embassy/Novosti/UN in the pilot window.
Operator
Not a math symbol - a recoding habit attached to a stretch of text: putting “artificial famine” in scare quotes, renaming a symposium a “gathering” (сборище), answering famine talk with drought and kulak sabotage. Operators are what change when the same theme crosses from secret to public. Example: spr. 1206 writes “symposium” in quotes; the April embassy release never names Montreal.
Shell
One of four zones in the archive, each with different rules about what may be said: (1) secret KGB memos, (2) autocommunication reports, (3) Soviet outward tier (embassy, Novosti, UN), (4) rival/diaspora/mainstream foil. Same calendar week, incompatible reader contracts.
Register
The document type plus audience contract - who the text is for and what genre allows. Register is why “famine” on spr. 1206 (quoted enemy lie) and “famine” on the embassy release (denial of artificial famine) are not the same sign-event.
Sign-event
The smallest unit we score: a stretch of text on a surface, on a date, with active operators, at a proof tier. Vectors attach to sign-events, not to dictionary lemmas.
Semiosis
How meaning moves between texts under institutional rules - not a word sitting in a dictionary. In this project: typed relay across surfaces (secret → outward → rival), with forbidden paths and documented silences.
Semiosphere (L1)
Lotman’s term, operationalized here as a map of surfaces and relay arcs: which paths are proven, tier-B, promising, forbidden, or missing. Location in culture = relay position, not word frequency.
Relay
Movement of a theme or operator from one surface to another - e.g. famine language from spr. 1206 toward the April embassy packet. Relay can transform operators (quoted lie → drought denial) or stop (symposium → no Montreal sentence).
Partial map
Shell-to-shell translation that does not always have an answer. Some operators map cleanly; others hit ⊥ (no outward translation). Treating relay as a total function would fake a symmetry the archive refuses.
⊥ (bottom / untranslatable)
Symbol for no licensed translation on that shell and date - not a software error. A zero column in the L2 tensor, or a documented miss (embassy release does not name Montreal).
Untranslatability
What cannot cross a boundary unchanged, structurally - not a translator’s failure. In this corpus: scare quotes stay internal; symposium has no embassy counterpart. Empirical = empty tensor cell or documented miss.
Documented miss
When pair-read shows an expected outward sentence is absent - e.g. the embassy release discusses drought but never names the Montreal meeting the memo tracked. The absence is evidence about the filter, not a gap in the search.
Silence (as coordinate)
When a channel does not carry a frame you might expect - e.g. domestic Pravda/Izvestiia not printing the drought denial in the processed 1983 window. Silence tells you which channel has which job, not that sources are missing.
Pair-read
The warrant chain: read a secret stretch beside its dated outward counterpart (or record a documented absence). Every historical claim and every geometric check ultimately answers to pair-read - not to the probe alone.
Embedding / encoder
A numeric fingerprint of a sentence from a frozen language model. Nearby fingerprints often share topic; they routinely miss scare quotes, gathering recodes, and other register-specific operators. Appendix: language encoding
Manifold (single-manifold assumption)
The ML default: all texts live in one shared meaning space, and closeness ≈ understanding. Montreal falsifies this - secret and public texts are not dialect variants on the same plane.
Cosine similarity
The angle between two fingerprint vectors - “how pointy in the same direction.” High cosine ≈ same topic neighborhood. It does not mean register-faithful translation or operator preservation.
Probe (semiosphere feature-space probe)
A small computational check: freeze an encoder, embed 25 scored stretches, fit a thin secret→outward map, compare to shuffled and rival controls. Confirms theme-level linearity; falsifies careless register merge. Microscope, not oracle.
Orthogonal Procrustes
A way to align two sets of fingerprints by rotating one space to match the other - like turning a transparency until paired points line up, without stretching. Used here for secret→outward map W.
Ridge (unconstrained linear map)
A looser map than Procrustes: can stretch and compress dimensions to fit pairs better. Higher score (0.756 in-sample) does not mean better historical reading - only easier curve-fitting.
LOTO (leave-one-topic-out)
Train the map on some themes, hold one topic out, test whether the rotation generalizes. With only nine secret→outward pairs, LOTO collapses to chance - the set is a dictionary, not a training corpus.
Explosion (L3, candidate)
Lotman’s term for a phase change in internal phrase co-occurrence after a boundary event. Here: after Montreal 1983, does the office’s internal wording network rewire while 1955 training-manual habits persist? Gated - not claimed from pilot counts alone.
Theme-level
Reading at the level of topic co-occurrence - famine near Canada, anniversary season. What generic embeddings recover easily. Insufficient for register-faithful history.
Register-level / register-faithful
Reading that tracks operator preservation - do scare quotes survive the relay? Does symposium become drought? This is what pair-read enforces and what a single manifold tends to collapse.
Register merge / collapse
When a system (human summary or ML model) averages secret and public into one voice - effectively reading the embassy release while smuggling in internal operators. The probe’s main negative result flags this failure mode.
Sheaf (informal intuition)
Borrowed from mathematics: each shell has local rules about what is speakable; you may only “glue” patches where pair-read proves a relay; obstructions (⊥, silence) block one global story. Formal write-up deferred to Phase 1.
Surface
A document venue in the corpus - spr. 1206, embassy press release no. 60, Novosti alias, Khmil UN speech, Ukrainian Weekly, Pravda (silence coordinate), etc. Surfaces are columns in the L2 tensor and nodes in the L1 semiosphere.
Proof tier
How strong the warrant is for a claim or edge: primary (fond memo in hand), tier-B processed (newspaper audit without every page imaged), documented miss, not claimed. Edges in L1 carry tier labels; the probe never upgrades tier.
Fiber (coordinate axis)
A named axis in the proposed coordinate system - shell, date, operator vector, proof tier, relay direction - as opposed to an unchosen dimension from a generic embedding. See sign-event coordinates.
