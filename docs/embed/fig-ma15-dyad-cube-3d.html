Four model pairings on a cube (MA15 pilot, 3D)

In the archived Llama run of MA12, swapping one size of a model for another on the return trip barely moved recovery (0.891). Lotman would have expected that, since he asks for generators that are built differently, and two sizes of one family are not. MA15 puts different families on each side of the round trip. Each ribbon is one pairing, running from the model that wrote the forward pass to the one that brought it back, and the thicker the ribbon, the more of the passage came home (mean token Jaccard).

How to read this

Each labelled cube is a model family. Ribbon colour shows which model wrote the forward pass, and the cone shows the direction of travel. Pick a pairing and press Play to send a pulse along it. qwen out and gemma back is the thick one at 0.743. Both pairings that come back through phi3:mini are thin, at roughly a third. Which model sits on the return side matters as much as whether the two models differ, so polyglottism turns out to be more than one knob.

This is a pilot: four dyads, the same thirteen stretches as MA12, one run on 2 October 2026. Read the ordering more than the decimals.

How this figure is made

Each panel opens one step on the way from the report file to the picture, with the equation it uses.

The measure: recovery for a pairing the number on each ribbon
Rf→g = (1/13) Σi=113 J( T(xi), T(g(f(xi))) ),   J(A, B) = |A ∩ B| / |A ∪ B|

The same recovery measure as MA12, the Jaccard index of word-token sets, averaged over the same thirteen stretches. The difference is that two different model families do the two halves.

SymbolStands for
fThe model that writes the forward pass.
gThe model that brings the text back, without seeing the original.
xiCorpus stretch i.
T(·)The set of word tokens in a text.
From recovery to a ribbon curve, thickness, colour, arrow
B(t) = (1 − t)² Pf + 2t(1 − t) M + t² Pg,   0 ≤ t ≤ 1

Each ribbon is a smooth curve from the forward model's corner Pf to the return model's corner Pg, pulled toward a control point M. M is the midpoint pushed 0.7 units sideways, and up or down a little. The two ribbons between qwen and gemma (one each way) bow to opposite sides so they don't overlap.

radius = 0.03 + 0.13 Rf→g

Thickness grows in a straight line with recovery but doesn't start at zero, so even the thinnest ribbon stays visible. The 0.743 ribbon has radius 0.127 and the 0.31 ribbon 0.070. A ribbon twice as thick does not mean twice the recovery, so read the printed number.

Colour is the forward model (qwen blue, gemma green). The cone sits 86% of the way along the curve and points along it, B′(0.86), showing the direction of travel. The corners are alternate corners of a cube, chosen only to spread the three families apart, so the distance between two corners means nothing.

What the motion does the pulse

Play sends a white pulse along the selected pairing. Its position t advances by 0.35 per second and wraps around, about three seconds per pass. With reduced motion switched on, Play is disabled and the pulse rests at the arrival end. The scene draws nothing while it is still.

Where the numbers and code live

The four scores are typed into the page from ma15_polyglottism_report.json (pilot run, 2026-10-02). The 0.743 for qwen out and gemma back, and the range of 0.31 to 0.37 for returns through phi3:mini, are also stated in journal §14. The 0.52 for gemma out and qwen back appears only in this figure's data and is still being checked against the report. The drawing code is the script at the bottom of this page, using assets/fig3d.js and Three.js r128.

In plain words

What you are looking at

  • Each brown cube is a small open language model from a different family: qwen2.5:3b, gemma2:2b and phi3:mini.
  • Each ribbon is one experiment. The model at the start rewrote thirteen archive passages, and the model at the end tried to turn each rewrite back into the original without seeing it.
  • A thick ribbon means many of the original words came back. A thin one means most were lost.
  • The colour tells you which model went first, and the cone points the way the text travelled.

What it shows

qwen out and gemma back returns the most (0.743). The same two models the other way round return less (0.52). Anything that comes back through phi3:mini returns about a third. Direction matters: the same pair of models scores differently depending on which one goes first.

Why it matters

Lotman held that a thinking culture needs at least two generators built differently, which the site calls polyglottism. Many AI pipelines run two copies, or two sizes, of one model and call the result a conversation. In the archived MA12 run, two sizes of one model family barely lost anything on the way back, which is what Lotman would predict inside a single language.

The dissertation's archive has exactly that two-voice structure: secret memos and public releases written for different readers by different parts of the same state. This figure is the first test of whether AI pipelines can have it too. Different families do behave differently, so the answer is not a flat no. It is still a pilot with four pairings, and the full matrix has yet to be run.
