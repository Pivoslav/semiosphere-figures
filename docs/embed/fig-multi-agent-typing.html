Multi-agent hand-offs vs bilingual relay

Three schematics for section 10. They diagram the argument; no multi-agent experiment has been run on the Montreal plate, so nothing here carries counts. The Montreal numbers they refer to (6/6 tier confusion under flat retrieval, 100% vs 8.3% miss-or-target) come from sections 6 and the typed-graph relay. Measured round trips and cross-family dyads live in MA12 and journal §14.

Figure M1 · Untyped message pass vs typed hand-off

Same three agents, two edge vocabularies
relay · transformed, tier recorded miss · documented absence forbidden · refused crossing untyped text

Left: a default pipeline moves content. Nothing in the message says which surface it came from, so agent C can quote agent A's summary as an outward fact - the section 5 shape of the Globe and Mail claim. Right: the same hand-offs carry shell type, pair id, and proof tier, so refusal and documented absence are available moves.

Figure M2 · Persistence: window, shared window, layered memory

What survives to structure the next act of meaning
token influence (decays) shell position / ingress I-I loop (stays inner) pair-read warrant

Adding agents lengthens the strip; it does not add layers. Shared context is a longer window with the same decay, which is why the third strip is wider than the first but built from the same material. The semiosphere strip is stacked instead: fond, shell position, pair-read warrant, an inward loop that never crosses the filter, and dated ingress that retools operators without raising volume.

Figure M3 · Paraphrase in one manifold vs crossing a filter

Why agent A→B output is not translation
paraphrase · theme preserved transformed · operators change refused missing counterpart

Left: both agents run one model, one tokenizer, one geometry. Their exchange moves within the manifold, and topic is the only organiser - the condition section 6 measured as theme gravity. Right: a bilingual filter is partial. Some material crosses recoded, some is refused, and some expected outward sentence is simply absent, which is a finding rather than a gap to fill.
