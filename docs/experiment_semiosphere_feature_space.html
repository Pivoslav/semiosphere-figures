What this is borrowing

Mikolov, Le, and Sutskever (2013) showed that one embedding space can be mapped onto another by a linear transform. Xing, Wang, Liu, and Lin (2015) and Artetxe, Labaka, and Agirre (2016) tightened that map to an orthogonal Procrustes problem after length-normalization and mean-centering. Hewitt and Manning (2019) used a linear transform of a frozen representation as a probe; Alain and Bengio (2017) did the same with a linear classifier. Hewitt and Liang (2019) required a control task: if a shuffled pairing fits as well, the geometry is not the recoding. The object here is Lotman’s bilingual filter, not machine translation.

Leave one topic out

Training on one topic family and testing on the other. Nine secret→outward pairs is a dictionary, not a training set; if the held-out cosine collapses to the shuffled control, the linear map memorized the famine packet or the UN packet and did not learn a register rotation that travels.
